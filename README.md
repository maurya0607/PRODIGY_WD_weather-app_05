# Weather App 🌦️

## 📌 Project Overview
This project is a **Weather Web Application** developed as **Task-05** for **ProDigy Infotech Internship**.  
The application fetches **real-time weather data** from a weather API based on the **user’s current location** or a **user-inputted city name** and displays essential weather information in a clean, modern UI.

The design uses **blue gradient squares and circular gradient elements** to enhance visual appeal.

---

## 🚀 Features
- Fetch weather data using Weather API
- Search weather by city name
- Get weather using user's current location
- Display temperature, weather condition & humidity
- Responsive and user-friendly design
- Gradient-based modern UI

---

## 🛠️ Technologies Used
- **HTML** – Structure of the web page  
- **CSS** – Styling, gradients & responsiveness  
- **JavaScript** – API integration & logic  
- **Weather API** – Real-time weather data
